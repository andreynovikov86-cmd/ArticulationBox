# ArticulationBox has moved

ArticulationBox is now maintained in [ReaScripts / ArticulationBox](https://github.com/andreynovikov86-cmd/ReaScripts/tree/main/ArticulationBox).

Use the [current installation and migration guide](https://github.com/andreynovikov86-cmd/ReaScripts/blob/main/ArticulationBox/README.md).

New ReaPack repository URL:

```text
https://raw.githubusercontent.com/andreynovikov86-cmd/ReaScripts/main/index.xml
```

Existing installations can keep using **Extensions → ReaPack → Synchronize packages**. Reinstallation and shortcut reassignment are not needed for these updates: the package identity, installed file names and former index URL are preserved.

The compatibility index mirrors ArticulationBox releases from ReaScripts. GitHub checks on an hourly schedule; runs can be delayed. Other ReaScripts packages are excluded from this index. Use the shared URL above for a new installation.

Release history is preserved; development and new releases live in ReaScripts.
