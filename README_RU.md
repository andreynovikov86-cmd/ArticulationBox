# ArticulationBox переехал

ArticulationBox теперь находится в [ReaScripts / ArticulationBox](https://github.com/andreynovikov86-cmd/ReaScripts/tree/main/ArticulationBox).

Откройте [актуальную инструкцию установки и перехода](https://github.com/andreynovikov86-cmd/ReaScripts/blob/main/ArticulationBox/README_RU.md).

Новый адрес репозитория ReaPack:

```text
https://raw.githubusercontent.com/andreynovikov86-cmd/ReaScripts/main/index.xml
```

Существующие установки продолжают обновляться через **Extensions → ReaPack → Synchronize packages**. Переустановка и переназначение клавиш для этого не нужны: имя пакета, устанавливаемые файлы и прежний адрес индекса сохранены.

Индекс совместимости получает версии ArticulationBox из ReaScripts. GitHub проверяет обновления по часовому расписанию; запуск может задерживаться. Другие пакеты ReaScripts в этот индекс не добавляются. Для новой установки используйте общий адрес выше.

История выпусков сохранена; разработка и новые версии находятся в ReaScripts.
