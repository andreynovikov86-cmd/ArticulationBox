# Руководство ArticulationBox

[English](USER_GUIDE.md) · **Русский** · [Репозиторий](https://github.com/andreynovikov86-cmd/ArticulationBox)

В полном меню поля есть **Help** с короткими объяснениями на английском. Эта справка работает без интернета. Быстрое меню у курсора содержит готовые артикуляции и сохранённые независимые Controller.

## 1. Быстрый старт

1. Откройте MIDI-айтем и запустите `Articulation_Manager.lua`. Оставляйте его работающим во время редактирования.
2. Создайте банк: **Settings > Banks > New**.
3. Нажмите **Add / Edit articulation**, выберите способ переключения и укажите параметры из документации вашего инструмента.
4. Выделите музыкальные ноты, откройте меню поля и выберите артикуляцию.
5. При необходимости задайте **Default articulation** для нот без отдельного назначения.
6. Сохраните проект REAPER.

Для быстрого выбора назначьте горячую клавишу на `Articulation_Quick_Menu.lua` в разделе экшнов **MIDI Editor**.

## 2. Создание и назначение артикуляций

При добавлении или редактировании выберите способ переключения:

| Способ | Что происходит |
| --- | --- |
| Channel | Музыкальная нота отправляется на указанный MIDI-канал. |
| Keyswitch | Создаётся служебная MIDI-нота, переключающая звук инструмента; она может срабатывать до начала музыкальной ноты или после него. |
| KS + Channel | Одновременно меняется канал музыкальной ноты и добавляется keyswitch. |
| Controller | Сохраняется отдельный именованный контроллер для применения к любым артикуляциям. |

Все параметры находятся в одном компактном окне **Add / Edit articulation**. Строка **Bank** показывает, куда сохраняются записи. В списке **Articulation** выберите **Add New** для добавления или сохранённую запись для редактирования. Кнопка **Remove articulation** внутри окна удаляет выбранную запись из банка, сохраняя существующие MIDI-назначения. Кнопки **Keyswitch**, **Channel**, **KS + Channel** показывают соответствующие поля. **Save** сохраняет запись, оставляя окно открытым. **Save & Next** сохраняет текущую запись и всегда выбирает **Add New**: название очищается, остальные параметры сохраняются. Нажатие клавиши, для которой ещё нет артикуляции, также переводит в **Add New** с пустым именем, сохраняя предыдущую артикуляцию. Имя последней сохранённой артикуляции остаётся видно. Строки piano roll подписываются сразу после каждого сохранения. **Add variant** копирует имя и параметры выбранной записи в новую, оставляя оригинал без изменений. Имя сохраняется для удобной правки; **Save & Next** по-прежнему очищает имя. **Cancel** отменяет только текущую несохранённую запись. Размер окна можно менять за края; он запоминается после закрытия и перезапуска REAPER.

При нажатии клавиши MIDI-контроллера автоматически подставляются KS note и KS velocity. При клике на клавише пианоролла используются активная строка и стандартная velocity новых нот REAPER. Если такая KS note уже есть в банке, загружаются также её название и параметры; точное совпадение velocity выбирает соответствующий вариант. Для отдельной копии нажмите **Add variant**. Оба значения можно исправить вручную; правка остаётся до нового нажатия. Подхват сам не создаёт и не записывает MIDI-ноты.

Скрипт не определяет настройки библиотеки самостоятельно: высоту keyswitch, velocity и каналы нужно указать в соответствии с инструментом.

| Поле | Значение |
| --- | --- |
| Name | Название в меню и на строках артикуляций. |
| Channel | Канал музыкальной ноты, от 1 до 16; используется в режимах с переключением канала. |
| KS note | Номер MIDI-ноты от 0 до 127. Для новой артикуляции берётся активная строка пианоролла. Числовой номер позволяет избежать различий в обозначении октав у библиотек. |
| KS velocity | Velocity служебной ноты, от 1 до 127. Некоторые библиотеки выбирают по этому значению вариант звукоизвлечения. |
| Trigger | Before note start — до начала ноты; After note start — после начала. |
| Delay (ms) | Величина опережения или задержки в миллисекундах. Учитываются MIDI-тики, границы айтема и соседние переключатели. |
| KS channel | Канал keyswitch: 0 — канал музыкальной ноты; 1–16 — явно заданный канал. |

Выделите музыкальные ноты и выберите название в меню, чтобы применить артикуляцию. **Clear articulation** снимает отдельное назначение; после этого может снова примениться артикуляция по умолчанию.

В полном меню список спрятан в **Articulations →**, поэтому большое количество записей не увеличивает высоту основного меню. По горячей клавише список открывается сразу. Записи с одинаковой KS note и маршрутизацией, но разной velocity объединяются в подменю. Название подменю задаётся отдельно в **Group name**; у старых групп до переименования используется имя варианта с наибольшей velocity. Варианты отсортированы от большей к меньшей. У каждого сохраняются собственное название и точная velocity.

Названия отсортированы по убыванию KS pitch: более высокая нота находится выше в списке. Галочка показывает, что артикуляция используется выделенными нотами; при смешанном выделении рядом появляется число соответствующих нот.

Редактирование записи банка не переписывает автоматически все старые назначения во всех айтемах: они хранят свои параметры. Чтобы применить новый pitch или канал к старым нотам, выберите их и назначьте артикуляцию заново. Отдельная команда настройки времени обновляет время назначений текущего банка в активном MIDI-тейке.

## 3. Что показывает поле

- Название — у выделенных нот одна артикуляция.
- **Mixed** — в выделении разные назначения либо сочетание назначенных и неназначенных нот.
- Прочерк — назначение отсутствует.
- Если ноты не выделены — название артикуляции по умолчанию, если она задана; иначе прочерк.

## 4. Артикуляция по умолчанию

Выберите её в **Default articulation**. Ноты без отдельного назначения используют её автоматически, пока каналом не управляет вручную нарисованный переключатель. **None** отключает дефолт. Артикуляция по умолчанию должна содержать keyswitch; режим только MIDI channel для неё недоступен.

Пример: назначьте Arco по умолчанию, затем выделите несколько нот и примените Staccato. На следующих нотах без отдельного назначения скрипт вернёт Arco. Если одновременно на одном канале нужны разные звуки, одного дефолта недостаточно: нужна подходящая маршрутизация инструмента либо небольшой автосдвиг начала нот.

## 5. Банки и сохранение

**Banks** выбирает банк для текущего трека. **Settings > Banks** создаёт, переименовывает, удаляет, импортирует и экспортирует банки.

Банки треков независимы. Новый трек начинает с **Empty bank**, а сохранённые шаблоны банков остаются доступными для выбора. Если выбран **Empty bank**, команда **Add / Edit articulation** сначала открывает **New bank**: введите имя банка. Банк сразу сохраняется и выбирается, после чего открывается редактор. Отмена оставляет редактор закрытым и ничего не создаёт. Поле имени расширено при создании и переименовании банка. Изменения банков и артикуляций сохраняются автоматически. Сохраняйте также проект REAPER: в нём находятся выбор банка на треке и назначения нот.

**Export** выгружает все банки текущего трека в один файл. **Import** добавляет банки из такого файла. Экспортируйте банки для резервной копии и переноса на другой компьютер.

Удаление банка или записи артикуляции не стирает уже существующие MIDI-назначения. Чтобы снять отдельное назначение с нот, используйте **Clear articulation**.

Оформление и общие настройки воспроизведения запоминаются между запусками REAPER. Команда **Keyswitch timing** также обновляет параметры текущего банка; выбранный банк и сами наборы артикуляций остаются индивидуальными для треков.

## 6. Ручные keyswitch

На строках артикуляций можно рисовать и редактировать MIDI-ноты вручную. Они считаются ручными переключателями и не получают дефолтную артикуляцию. Без дефолта последний ручной переключатель действует до следующего переключения. С выбранным дефолтом ручной переключатель действует на ноты в нарисованном участке, а последующие ноты без отдельных назначений получают дефолт.

Когда начинается следующий keyswitch, предыдущая нота переключения сокращается до его начала. Длина музыкальных нот при этом сохраняется. Разные keyswitch с точно одинаковым началом на одном канале остаются неоднозначными.

Если отдельно изменить pitch, положение, длину или velocity автоматического keyswitch, он становится ручным. Старые автоматические привязки снимаются, музыкальные ноты сохраняются. Чтобы сохранить автоматическую связь, перемещайте саму музыкальную ноту.

## 7. Время и воспроизведение

Автоматический keyswitch может начинаться до музыкальной ноты или после её начала, в зависимости от **Trigger**. Он продолжается до конца музыкальной ноты. Если раньше начинается другой переключатель, предыдущий заканчивается в этой точке.

**Keyswitch timing** задаёт величину опережения/задержки для текущего банка, сохраняя выбранное направление Before/After, обновляет его назначения в активном тейке и сохраняет исходные значения для новых артикуляций. Поля **Length** и **Overlap after note** оставлены для совместимости: в текущем поведении **Follow musical note** они не задают конечную длину переключателя.

Пример окончания лупа: задайте **After note start**, **Delay 1 ms**, **KS velocity 100**. Аккорд может при этом иметь velocity 1: скрипт её не меняет. Длина переключателя следует концу музыкальной ноты; отдельной настройки длины в окне нет. Если задержка выходит за конец ноты, используется минимальная длина в один MIDI-тик в пределах айтема.

**Chase MIDI note-ons** включает соответствующую настройку REAPER, чтобы при старте воспроизведения внутри длинной ноты она могла отправляться повторно. Это помогает со стартом внутри keyswitch; результат нужно проверить на конкретном инструменте.

**Auto-stagger conflicting notes** немного задерживает начала музыкальных нот с конфликтующими автоматическими артикуляциями. Конец каждой ноты остаётся на месте, поэтому её длина сокращается на величину сдвига. **Auto-stagger spacing** задаёт интервал 0.1–50 мс; разрешение MIDI в тиках может увеличить минимальный фактический сдвиг. Общий защитный предел — 50 мс.

Автосдвиг разносит переключения во времени, но не создаёт независимые одновременные состояния инструмента на одном MIDI-канале.

## 8. Перемещение и транспонирование

Основной скрипт должен оставаться запущенным. Перемещение и изменение длины музыкальных нот обновляют связанные автоматические keyswitch. Если вернуть одинаковую артикуляцию, ранее сдвинутые из-за конфликта начала могут восстановиться.

Если у самого начала айтема нет места для keyswitch в режиме Before, либо при включённом автосдвиге соседние начала не оставляют свободного MIDI-тика, музыкальная нота может немного сдвинуться вправо. Её конец сохраняется. При добавлении новых нот в аккорд явные назначения существующих нот сохраняются; новые ноты получают дефолт, а конфликтующие начала разносит автосдвиг.

При общем выделении и транспонировании скрипт защищает высоты keyswitch, а музыкальные ноты меняют высоту. При изменении pitch всего айтема/тейка скрипт переносит транспонирование в музыкальные ноты и обнуляет pitch тейка. Поэтому надпись **P+…** на айтеме может исчезнуть.

Для отмены редактирования используйте обычный **Undo** в REAPER. Сопровождение и защита высоты требуют работающего основного скрипта.

## 11. Если что-то непонятно

- **Не открывается окно параметров:** установите ReaImGui через ReaPack и перезапустите REAPER.
- **Звук не переключается:** проверьте KS pitch, velocity, каналы и настройки самого инструмента.
- **Список пуст:** выберите банк именно текущего трека и добавьте артикуляции.
- **Нет настроек в меню:** откройте поле или `Articulation_Menu_Popup.lua`; короткое меню содержит только артикуляции.
- **Переключение остаётся после удаления keyswitch:** используйте **Clear missing keyswitch assignments**, затем проверьте дефолтную артикуляцию.
- **Скрипт не сопровождает ноты:** убедитесь, что основной скрипт запущен, а не только быстрое меню.
- **Нужно понять последнюю ошибку:** откройте **Help > Status** или **Settings > Status**.

Сохраняйте проект и экспортируйте банки перед переносом настроек на другой компьютер. Установка и обновление описаны в [INSTALL_RU](INSTALL_RU.txt).

## Controller: отдельно или вместе с артикуляцией

В окне **Add / Edit articulation** есть четвёртый тип **Controller**. Он создаёт независимый именованный контроллер в текущем банке. После сохранения в полном и быстром меню появляется подменю **Controller**. Подменю также появляется для сброса контроллеров, связанных с артикуляциями или назначенных выделенным нотам. Выделите музыкальные ноты и выберите контроллер: их артикуляция сохранится.

В режимах **Keyswitch**, **Channel**, **KS + Channel** поле **Controller** добавляет контроллер к самой артикуляции. **None** отключает это дополнение. Таким образом, один контроллер можно использовать отдельно с разными артикуляциями либо сохранить вместе с конкретной.

Первый пункт — **None**, он выбран по умолчанию. Далее идут **Pitch Bend**, **Mod Wheel (CC 1)**, **Hold Pedal (CC 64)** и остальные CC. Простое переключение на Controller не назначает Pitch Bend. Значения CC: **0–127**. Pitch Bend: **−8192…8191**, центр — **0**. Для Hold Pedal обычно задают **127**, а **Reset value 0** отпускает педаль. Точное действие зависит от настроек инструмента.

**Length** задаёт время действия:

| Режим | Когда отправляется значение и сброс |
| --- | --- |
| Full note | Значение немного до начала ноты, сброс немного после её конца. |
| Note start | Короткий импульс: начинается до начала ноты, заканчивается после начала. |
| Note end | Значение перед концом ещё звучащей ноты, сброс немного после её отпускания. |

**Before (ms)** и **After (ms)** задают запас времени по обе стороны выбранной границы. Минимум — один MIDI-тик: фактический интервал может оказаться больше заданного. **Reset value** — значение, отправляемое при окончании действия. **Control channel 0** использует канал музыкальной ноты; **1–16** задаёт отдельный канал.

Контроллеры следуют за перемещением и изменением длины нот, пока работает основной скрипт. У начала айтема нота может немного сдвинуться вправо, чтобы осталось место для предварительного события; её конец остаётся на месте. Если сброс выходит за конец айтема, айтем удлиняется, чтобы сброс прозвучал. Undo/Redo отменяет и возвращает эти изменения вместе.

Контроллер действует на весь MIDI-канал. Для одновременно звучащих нот одного канала нельзя задать независимые состояния одного контроллера. Более позднее назначение на той же линии заменяет предыдущее. Независимый контроллер имеет приоритет перед связанным с артикуляцией на той же линии; повторное назначение артикуляции возвращает её контроллер. Контроллеры других линий сохраняются.

**Controller > Reset controllers** снимает все контроллеры с выделенных нот, сохраняя артикуляцию. Пункт неактивен, если у выделенных нот нет контроллеров. **Settings > Clear controller assignments** выполняет то же действие. Удаление записи контроллера из банка сохраняет уже существующие MIDI-назначения. Контроллеры сохраняются вместе с индивидуальным банком трека; для их переноса используйте Export/Import и сохраняйте проект REAPER.

Галочка возле артикуляции означает, что она назначена выделенным нотам. Наличие записи в банке проверяется в списке **Articulation** окна **Add / Edit articulation**; строка **Bank** показывает, к какому банку относится запись.

**Default articulation** находится в основном меню сразу под **Banks** и неактивен при **Empty bank**. При **Add variant** сначала задаётся **Group name**. Отмена оставляет исходную артикуляцию без изменений. Поле **Group name** появляется при редактировании группы вариантов и меняет название подменю, сохраняя имена самих вариантов. У одиночных артикуляций поле скрыто. Имя группы сохраняется в банке, включая Export/Import.

## Окончания: Ending

Выберите **Type → Ending** в редакторе, задайте KS note, KS velocity, KS channel и Delay, затем сохраните. В подменю **Ending** попадают только записи этого типа. Обычные артикуляции туда не попадают. Переключение сохранённой основной записи на тип Ending готовит отдельную новую запись, сохраняя оригинал. Выделите музыкальные ноты, назначьте **Articulations → Open** или Slap, затем **Ending → Slide Down**. У ноты будут две независимые привязки. Окончание сохраняет основную артикуляцию и канал музыкальной ноты. **Ending → Clear ending** снимает только окончание, а **Clear articulation** оставляет окончание на месте. Окончания нельзя выбирать как дефолт.

Для **Note end** поле **Delay (ms)** означает расстояние **до конца ноты**. Keyswitch начинается немного до её отпускания, пока голос ещё звучит, и заканчивается вместе с нотой. Минимум — один MIDI-тик до конца. Положение ограничено длиной ноты; если места совсем нет, операция отменяется без изменения MIDI. При перемещении и изменении длины ноты окончание следует за ней, пока работает основной скрипт. KS velocity и KS channel задаются отдельно; velocity музыкальной ноты сохраняется. Состояние keyswitch общее для MIDI-канала.

Сохраняйте проект. Изменение записи банка не переписывает прежние назначения: чтобы обновить их, выберите ноты и назначьте Ending повторно.

## Редактирование и быстродействие

Окно Add / Edit можно оставлять открытым при перемещении и изменении длины нот: основные артикуляции, Ending и контроллеры продолжают следовать за ними. Во время предварительного просмотра в штатном окне Quantize Events автоматическая запись MIDI приостанавливается; после закрытия окна привязки обновляются. Простое выделение, включая Command+A, обрабатывается отдельно и не пересоздаёт переключатели. При проигрывании и прокрутке без изменений MIDI используется сохранённое состояние. Обновление большой партии выполняется одной записью MIDI с проверкой сохранности музыкальных нот.
